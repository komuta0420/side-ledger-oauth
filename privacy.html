side-ledger プライバシーポリシー

最終更新日: 2026年11月9日

このツールについて

side-ledger は、開発者本人が自分の副業の帳簿を付けるためだけに使う私的なツールです。利用者は開発者本人の 1 名で、他の人のデータを扱うことはありません。

取得する情報

Google アカウントの許可を得て、Gmail API の読み取り専用の権限(gmail.readonly)で、開発者本人の受信メールを検索し、本文と添付ファイルを読み取ります。メールの送信、削除、変更は行いません。

利用目的

領収書や入金通知のメールから、日付・支払先・金額を読み取り、開発者本人のパソコンにある帳簿に記録するためにだけ使います。

保存と共有

読み取ったメールの内容と認証情報は、開発者本人のパソコンの中にだけ保存します。第三者への提供、販売、広告目的の利用は行いません。外部のサーバへ送信することもありません。

Google API サービスのユーザーデータに関するポリシー

Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー(限定的な利用の要件を含む)に従います。

権限の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもアクセス権を取り消せます。
